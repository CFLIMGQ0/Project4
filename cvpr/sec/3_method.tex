\section{Method}
\label{sec:method}

\begin{figure*}[t]
    \centering

    \caption[Overview of ALM-MIL.]{%

        LCCF 结合标签特异性视觉聚合、标签超图推理，以及带门控融合的标签条件文本检索，

    \label{fig:alm_mil_framework}

We propose Acquisition-aware Label-centric Multimodal Multiple Instance
Learning (ALM-MIL) for examination-level multimodal multi-label recognition.
For examination $i$, the input consists of an ordered sequence of $N_i$ images
and one paired report.  Sequences longer than the maximum length $T$ are
uniformly sampled, while shorter sequences are padded and marked with a
valid-image mask, yielding $T_i=\min(N_i,T)$ valid images.  The target is an
examination-level multi-label vector $y_i\in\{0,1\}^{L}$, where multiple
labels may be positive simultaneously.  As shown in
Fig.~\ref{fig:alm_mil_framework}, ALM-MIL encodes each valid image into an
instance representation, applies Acquisition-aware Contextual Position
Encoding (ACPE) and a bidirectional Transformer to model image relationships,
and encodes the category-masked report into token features.  Label-Centric
Coexistence Fusion (LCCF) then organizes visual and textual evidence around
each label through label-specific visual aggregation, coexistence reasoning,
and adaptive textual fusion, producing one representation for each of the
$L$ labels for final prediction.

\cntranslation{%
本文提出采集感知的标签中心多模态多实例学习框架
（Acquisition-aware Label-centric Multimodal Multiple Instance Learning，
ALM-MIL），用于检查级多模态多标签识别。对于检查 $i$，输入由 $N_i$ 张
有序图像和一份配对报告组成。当图像数量超过最大长度 $T$ 时进行等距采样，
否则补齐至 $T$ 并标记有效图像掩码，从而得到 $T_i=\min(N_i,T)$ 张有效图像。
目标为检查级多标签向量 $y_i\in\{0,1\}^{L}$，其中多个标签可以同时为正。
如图~\ref{fig:alm_mil_framework} 所示，ALM-MIL 首先将每张有效图像编码为
实例表征，再通过采集感知上下文位置编码（Acquisition-aware Contextual
Position Encoding，ACPE）和双向 Transformer 建模图像关系，并将经过类别
掩码的报告编码为 token 特征。随后，标签中心共存融合（Label-Centric
Coexistence Fusion，LCCF）围绕各个标签组织视觉与文本证据，通过标签级
视觉聚合、共存关系推理和自适应文本融合，为 $L$ 个标签分别生成表征并进行
最终预测。
}

\subsection{Acquisition-aware Contextual Position Encoding}
\label{sec:acpe}

\paragraph{Acquisition Anchoring.}
ACPE starts from the ordered slots of the retained images.  Let $t$ denote the
slot index of a retained image and define its normalized slot anchor as
\begin{equation}
r_{it}=\frac{t-1}{\max(T_i-1,1)}.
\label{eq:acpe_anchor_new}
\end{equation}
The corresponding raw slot gap is then
$\Delta r_{it}=r_{it}-r_{i,t-1}$.  This anchor provides the positional
reference from which ACPE constructs contextual coordinates.

\cntranslation{%
\textbf{采集锚定。}
ACPE 从保留图像的有序槽位开始。令 $t$ 表示保留图像的槽位索引，并将其
归一化为槽位锚点
\[
r_{it}=\frac{t-1}{\max(T_i-1,1)}.
\]
随后，对应的原始槽位间距定义为
$\Delta r_{it}=r_{it}-r_{i,t-1}$。该锚点为 ACPE 构建上下文坐标提供位置参照。
}

\paragraph{Visual Context Descriptor and Deformation Estimation.}
To make each interval responsive to local visual context, let $u_{it}$ denote
the projected visual feature of the $t$-th retained image.  We jointly encode
the feature changes on the two sides of the current image, their strengths,
and their cross-side relation:
\begin{equation}
\left\{
\begin{aligned}
\delta^-_{it}&=u_{it}-u_{i,t-1},\qquad
\delta^+_{it}=u_{i,t+1}-u_{it},\\
m^-_{it}&=|\delta^-_{it}|,\qquad
m^+_{it}=|\delta^+_{it}|,\\
q_{it}&=\delta^-_{it}\odot\delta^+_{it}.
\end{aligned}
\right.
\label{eq:acpe_visual_context}
\end{equation}
The signed transitions $\delta^-_{it}$ and $\delta^+_{it}$ describe the feature changes
from the previous image to the current image and from the current image to the
next image, respectively.  The magnitudes $m^-_{it}$ and $m^+_{it}$ measure
the element-wise strength of these two changes without retaining their signs.
The interaction $q_{it}$ compares the two transitions element-wise: positive
components indicate same-direction continuation, whereas negative components
indicate a reversal.  We use these visual cues to form the context descriptor
\begin{equation}
\begin{aligned}
\xi_{it}=\bigl[&u_{it},\delta^-_{it},\delta^+_{it},
m^-_{it},m^+_{it},\\[-1mm]
&q_{it}\bigr].
\end{aligned}
\label{eq:acpe_descriptor}
\end{equation}
The descriptor $\xi_{it}$ collects these visual cues and is provided to the
deformation estimator.
An MLP produces a bounded deformation through
\begin{equation}
\eta_{it}=\alpha\tanh\!\bigl(f_\eta(\xi_{it})\bigr),
\label{eq:acpe_deformation}
\end{equation}
$f_\eta$ denotes the MLP; $\alpha>0$ controls the deformation range; and
$\eta_{it}$ is the scalar deformation assigned to the interval between the
previous and current retained images.

\cntranslation{%
\textbf{视觉上下文描述与变形估计。}
为使每个间隔能够响应局部视觉上下文，令 $u_{it}$ 表示第 $t$ 张保留图像的投影视觉特征。我们联合编码当前图像两侧的特征变化、变化强度以及两侧关系：
\[
\left\{
\begin{aligned}
\delta^-_{it}&=u_{it}-u_{i,t-1},\qquad
\delta^+_{it}=u_{i,t+1}-u_{it},\\
m^-_{it}&=|\delta^-_{it}|,\qquad
m^+_{it}=|\delta^+_{it}|,\\
q_{it}&=\delta^-_{it}\odot\delta^+_{it}.
\end{aligned}
\right.
\]
其中，$\delta^-_{it}$ 和 $\delta^+_{it}$ 分别表示从前一张图像到当前图像以及从当前图像到后一张图像的有符号特征变化；$m^-_{it}$ 和 $m^+_{it}$ 表示两侧变化的逐元素强度，不保留变化的符号；$q_{it}$ 是两个有符号转变的逐元素交互项，正分量表示同向延续，负分量表示变化反转。
我们使用这些视觉线索构成上下文描述：
\[
\xi_{it}=\bigl[u_{it},\delta^-_{it},\delta^+_{it},
m^-_{it},m^+_{it},q_{it}\bigr].
\]
其中，$\xi_{it}$ 是输入变形估计器的上下文描述子。
多层感知机根据该描述子产生有界变形量：
\[
\eta_{it}=\alpha\tanh\!\bigl(f_\eta(\xi_{it})\bigr),
\]
其中，$f_\eta$ 表示多层感知机，$\alpha>0$ 控制变形范围，$\eta_{it}$ 表示分配给前一张与当前保留图像之间间隔的标量变形量。
}

\paragraph{Contextual Coordinate Construction.}
The deformation changes how much contextual distance is assigned to each
adjacent pair while keeping the acquisition anchors as the reference.  First,
each raw gap is reweighted by the predicted deformation:
\begin{equation}
g_{it}=\Delta r_{it}\exp(\eta_{it}).
\label{eq:acpe_adjusted_gap}
\end{equation}
Here $g_{it}$ is the deformation-adjusted gap.  We normalize all adjusted
gaps by their total and by the original endpoint span:
\begin{equation}
\widetilde g_{it}
=\frac{(r_{iT_i}-r_{i1})g_{it}}
{\max\{\sum_{k=2}^{T_i}g_{ik},\varepsilon\}}.
\label{eq:acpe_normalized_gap}
\end{equation}
$\widetilde g_{it}$ is the normalized contextual gap, and
$\varepsilon>0$ prevents an unstable zero denominator.  Accumulating these
normalized gaps from the first acquisition anchor gives
\begin{equation}
c_{it}=r_{i1}+\sum_{k=2}^{t}\widetilde g_{ik},
\qquad t=1,\ldots,T_i.
\label{eq:acpe_context_coordinate}
\end{equation}
The resulting $c_{it}$ is the cumulative contextual coordinate.  The
exponential factor is positive, so the adjusted gaps remain nonnegative and
retain the acquisition order while their relative sizes reflect local visual
change.  This preserves the total span between $r_{i1}$ and $r_{iT_i}$ while
allowing visually different intervals to receive different contextual
distances, and the resulting coordinate remains content-adaptive while
constrained by acquisition order and endpoints.

\cntranslation{%
\textbf{上下文坐标构建。}
变形量用于调整相邻图像之间分配的上下文距离，同时保留采集锚点作为参照。首先，按照预测变形对每个原始间距进行重加权：
\[
g_{it}=\Delta r_{it}\exp(\eta_{it}).
\]
其中，$g_{it}$ 表示经变形调整的间距。随后，按照所有调整后间距的总和与原始端点跨度对其进行归一化：
\[
\widetilde g_{it}
=\frac{(r_{iT_i}-r_{i1})g_{it}}
{\max\{\sum_{k=2}^{T_i}g_{ik},\varepsilon\}}.
\]
其中，$\widetilde g_{it}$ 表示归一化后的上下文间距，$\varepsilon>0$ 用于避免分母为零。最后，从首个采集锚点开始累积归一化间距，得到
\[
c_{it}=r_{i1}+\sum_{k=2}^{t}\widetilde g_{ik},
\qquad t=1,\ldots,T_i.
\]
其中，$c_{it}$ 表示累积得到的上下文坐标。由于指数因子始终为正，调整后的间距保持非负并遵循采集顺序，同时其相对大小反映局部视觉变化。归一化保持 $r_{i1}$ 与 $r_{iT_i}$ 之间的总跨度，使不同视觉变化的间隔获得不同的上下文距离；得到的坐标仍然受到采集顺序和端点的约束。
}

\paragraph{Dual-route Position Injection.}
ACPE injects the acquisition and contextual coordinates into the visual
Transformer through two complementary routes.

The absolute route assigns a positional signal to each image.  A continuous
Fourier mapping $\phi$ encodes its acquisition anchor
$r_{it}$, contextual coordinate $c_{it}$, and their difference $c_{it}-r_{it}$;
$f_{\mathrm{abs}}$ projects the concatenated encoding into the instance feature
space:
\begin{equation}
p^{\mathrm{abs}}_{it}
=
f_{\mathrm{abs}}\bigl(
[\phi(r_{it}),\phi(c_{it}),\phi(c_{it}-r_{it})]
\bigr).
\label{eq:acpe_abs_new}
\end{equation}
$p^{\mathrm{abs}}_{it}$ is added to the projected visual feature $u_{it}$
before the bidirectional Transformer.  The image feature thus carries both
its acquisition reference and its content-adjusted position.

The relative route acts on pairs of images.  For images $t$ and $u$, the raw
and contextual coordinate differences describe their signed separations;
the difference between these separations captures the adjustment made by
the contextual coordinates.  Each attention head $h$ maps these three terms
to a pairwise bias:
\begin{equation}
\begin{aligned}
b^{(h)}_{itu}
=
f^{(h)}_{\mathrm{rel}}\bigl(
[\phi(r_{it}-r_{iu}),
\phi(c_{it}-c_{iu}),\\[-1mm]
\phi((c_{it}-c_{iu})-(r_{it}-r_{iu}))]
\bigr).
\end{aligned}
\label{eq:acpe_rel_new}
\end{equation}
$f^{(h)}_{\mathrm{rel}}$ uses a scaled tanh output to bound
$b^{(h)}_{itu}$ within $[-2,2]$.  Adding this bias to the scaled dot-product
attention logits lets pairwise attention use both acquisition and contextual
separations.

\cntranslation{%
\textbf{双路径位置注入。}
ACPE 通过两条互补路径将采集坐标和上下文坐标注入视觉 Transformer。

绝对路径为每张图像生成位置表示：连续 Fourier 映射 $\phi$ 分别编码采集锚点 $r_{it}$、
上下文坐标 $c_{it}$ 及其差值 $c_{it}-r_{it}$，再由 $f_{\mathrm{abs}}$
将拼接后的编码投影到实例特征空间：
\[
p^{\mathrm{abs}}_{it}
=
f_{\mathrm{abs}}\bigl(
[\phi(r_{it}),\phi(c_{it}),\phi(c_{it}-r_{it})]
\bigr).
\]
$p^{\mathrm{abs}}_{it}$ 在双向 Transformer 之前加到投影视觉特征 $u_{it}$ 上，
使图像特征同时包含原始采集参照和随内容调整后的位置。

相对路径作用于图像对。对于图像 $t$ 和 $u$，原始坐标差与上下文坐标差
分别描述两者的有符号间隔；这两个间隔的差值反映上下文坐标带来的调整。
每个注意力头 $h$ 将这三项映射为图像对的偏置：
\[
\begin{aligned}
b^{(h)}_{itu}
=
f^{(h)}_{\mathrm{rel}}\bigl(
[\phi(r_{it}-r_{iu}),
\phi(c_{it}-c_{iu}),\\[-1mm]
\phi((c_{it}-c_{iu})-(r_{it}-r_{iu}))]
\bigr).
\end{aligned}
\]
$f^{(h)}_{\mathrm{rel}}$ 使用缩放后的 tanh 将 $b^{(h)}_{itu}$ 限制在
$[-2,2]$ 内。该偏置加到缩放点积注意力 logits 中，使图像对的注意力
同时利用采集间隔和上下文间隔。
}

\subsection{Label-Centric Coexistence Fusion}
\label{sec:lccf}

\paragraph{Label-wise Visual Evidence Aggregation.}
The input is the padded contextual image feature sequence
$H_i=(h_{i1},\ldots,h_{iT})\in\mathbb{R}^{T\times d}$.  Its retained rows
are indicated by the valid-image mask $m_{it}$.  The image features are first
transformed by a gated mapping shared by all labels:
\begin{equation}
v_{it}=\tanh(Vh_{it})\odot\sigma(Uh_{it}).
\label{eq:lccf_gate_new}
\end{equation}
For each label $\ell$, an independent vector $w_\ell$ scores the visual
evidence at each image:
\begin{equation}
e_{i\ell t}=w_\ell^{\top}v_{it}.
\label{eq:lccf_visual_score_new}
\end{equation}
The masked attention weight is
\begin{equation}
a_{i\ell t}
=\frac{m_{it}\exp(e_{i\ell t})}
{\sum_{u=1}^{T}m_{iu}\exp(e_{i\ell u})+\varepsilon}.
\label{eq:lccf_attention_new}
\end{equation}
where $m_{it}$ excludes padded positions from the normalization.  The
label-specific visual representation is then obtained as
\begin{equation}
z_{i\ell}=\sum_{t=1}^{T}a_{i\ell t}h_{it}.
\label{eq:lccf_visual_aggregate_new}
\end{equation}
The gated image mapping is shared across labels, while each label has its own
$w_\ell$, allowing different labels to select different images and share an
image when appropriate; stacking the outputs gives
$Z_i=[z_{i1},\ldots,z_{iL}]^{\top}\in\mathbb{R}^{L\times d}$.

\cntranslation{%
\textbf{标签级视觉证据聚合。}
输入为补齐后的上下文图像特征序列
$H_i=(h_{i1},\ldots,h_{iT})\in\mathbb{R}^{T\times d}$，有效图像位置由有效图像掩码 $m_{it}$ 标记。首先，使用在所有标签之间共享的门控映射变换每张图像的特征：
\[
v_{it}=\tanh(Vh_{it})\odot\sigma(Uh_{it}).
\]
对于每个标签 $\ell$，使用独立的向量 $w_\ell$ 对每张图像的视觉证据进行打分：
\[
e_{i\ell t}=w_\ell^{\top}v_{it}.
\]
带掩码的图像注意力权重为
\[
a_{i\ell t}
=\frac{m_{it}\exp(e_{i\ell t})}
{\sum_{u=1}^{T}m_{iu}\exp(e_{i\ell u})+\varepsilon}.
\]
其中，$m_{it}$ 用于在归一化时排除补齐位置。随后得到标签特异性的视觉表征：
\[
z_{i\ell}=\sum_{t=1}^{T}a_{i\ell t}h_{it}.
\]
图像特征变换在标签之间共享，而每个标签具有独立的 $w_\ell$，使不同标签能够选择不同图像，并在需要时共享同一图像的证据；将所有标签视觉表征堆叠得到
$Z_i=[z_{i1},\ldots,z_{iL}]^{\top}\in\mathbb{R}^{L\times d}$。
}

\paragraph{Coexistence-aware Hypergraph Reasoning.}
The rows of $Z_i$ are treated as $L$ label nodes.  We introduce $E$ latent
hyperedges with learnable label--hyperedge incidence parameters
$B\in\mathbb{R}^{L\times E}$.  Normalizing these parameters over labels and
over hyperedges gives $S_{\mathrm{node}\rightarrow\mathrm{edge}}$ and
$S_{\mathrm{edge}\rightarrow\mathrm{node}}$, respectively.  Node features
are first aggregated to the latent hyperedges:
\begin{equation}
U_i=S_{\mathrm{node}\rightarrow\mathrm{edge}}^{\top}f_m(Z_i).
\label{eq:lccf_node_edge_new}
\end{equation}
Here $U_i$ contains the latent hyperedge features; edge-to-node propagation
then gives
\begin{equation}
\widetilde Z_i=S_{\mathrm{edge}\rightarrow\mathrm{node}}U_i.
\label{eq:lccf_edge_node_new}
\end{equation}
$\widetilde Z_i$ is the hypergraph-refined message returned to the label
nodes, which is combined with the original label features through a residual
update:
\begin{equation}
Z_i^{\mathrm{img}}=Z_i+\rho([Z_i;\widetilde Z_i]).
\label{eq:lccf_hypergraph_new}
\end{equation}
Parameterized by $B$, the latent hypergraph exchanges higher-order information
among coexisting labels, while the residual connection preserves label-specific
visual evidence and $Z_i^{\mathrm{img}}\in\mathbb{R}^{L\times d}$ retains one
refined vector per label.

\cntranslation{%
\textbf{共存感知超图推理。}
$Z_i$ 的各行被视为 $L$ 个标签节点。引入 $E$ 条潜在超边，并使用可学习的标签—超边关联参数
$B\in\mathbb{R}^{L\times E}$。沿标签维度和超边维度分别对这些参数进行归一化，得到
$S_{\mathrm{node}\rightarrow\mathrm{edge}}$ 和
$S_{\mathrm{edge}\rightarrow\mathrm{node}}$。节点特征首先聚合到潜在超边：
\[
U_i=S_{\mathrm{node}\rightarrow\mathrm{edge}}^{\top}f_m(Z_i).
\]
其中，$U_i$ 表示潜在超边特征；随后进行超边到节点的传播：
\[
\widetilde Z_i=S_{\mathrm{edge}\rightarrow\mathrm{node}}U_i.
\]
$\widetilde Z_i$ 表示返回标签节点的超图细化消息，随后通过残差更新将其与原始标签特征结合：
\[
Z_i^{\mathrm{img}}=Z_i+\rho([Z_i;\widetilde Z_i]).
\]
以 $B$ 为可学习参数的潜在超图通过共享超边在共存标签之间交换高阶信息，同时由残差连接保留标签特异性的视觉证据，使
$Z_i^{\mathrm{img}}\in\mathbb{R}^{L\times d}$ 为每个标签保留一个细化向量。
}

\paragraph{Label-conditioned Textual Evidence Integration.}
The refined visual matrix $Z_i^{\mathrm{img}}$ and token-level report
features $F_i^{\mathrm{txt}}\in\mathbb{R}^{K_i\times d}$ are used to retrieve
and adaptively inject textual evidence.  The paired report is category-masked
and encoded at the token level.  For label $\ell$, a learnable label
embedding $u_\ell$ is added to its visual representation to form the query
\begin{equation}
q_{i\ell}=z_{i\ell}^{\mathrm{img}}+u_\ell.
\label{eq:lccf_query_new}
\end{equation}
Using $q_{i\ell}$ as the query and the report tokens as keys and values, a
masked multi-head cross-attention module obtains
\begin{equation}
z_{i\ell}^{\mathrm{txt}}
=\operatorname{CrossAttn}\!\left(q_{i\ell},F_i^{\mathrm{txt}},F_i^{\mathrm{txt}}\right).
\label{eq:lccf_text_retrieval_new}
\end{equation}
Applying the report padding mask to the token keys and values, independent
label queries produce label-specific attention distributions from the same
report, yielding
$Z_i^{\mathrm{txt}}=[z_{i1}^{\mathrm{txt}},\ldots,
z_{iL}^{\mathrm{txt}}]^{\top}\in\mathbb{R}^{L\times d}$.

To control the contribution of the retrieved evidence, we compute a scalar
gate for each examination--label pair:
\begin{equation}
g_{i\ell}=a_i\,\sigma\!\left(\rho_g([z_{i\ell}^{\mathrm{img}};z_{i\ell}^{\mathrm{txt}}])\right),
\label{eq:lccf_gate_fusion_new}
\end{equation}
and fuse it with the visual representation through a residual connection:
\begin{equation}
z_{i\ell}^{\mathrm{fuse}}
=z_{i\ell}^{\mathrm{img}}+g_{i\ell}z_{i\ell}^{\mathrm{txt}}.
\label{eq:lccf_fusion_new}
\end{equation}
With $a_i=0$ when no valid report is available, the gate adapts the textual
contribution while the residual path preserves label-specific visual evidence,
yielding
$Z_i^{\mathrm{fuse}}=[z_{i1}^{\mathrm{fuse}},\ldots,z_{iL}^{\mathrm{fuse}}]^{\top}
\in\mathbb{R}^{L\times d}$.

\cntranslation{%
\textbf{标签条件文本证据整合。}
细化后的视觉矩阵 $Z_i^{\mathrm{img}}$ 与报告的 token 级特征
$F_i^{\mathrm{txt}}\in\mathbb{R}^{K_i\times d}$ 用于检索并自适应注入文本证据。
配对报告经过类别名称掩码，并保留 token 级表征。对于标签 $\ell$，将可学习的
标签嵌入 $u_\ell$ 加到对应的视觉表征上，形成查询
\[
q_{i\ell}=z_{i\ell}^{\mathrm{img}}+u_\ell.
\]
以 $q_{i\ell}$ 为查询、报告 token 为键和值，使用带掩码的多头交叉注意力得到
\[
z_{i\ell}^{\mathrm{txt}}
=\operatorname{CrossAttn}\!\left(q_{i\ell},F_i^{\mathrm{txt}},F_i^{\mathrm{txt}}\right).
\]
报告补齐位置的掩码作用于 token 的键和值；不同标签通过独立查询从同一份报告
中产生标签特异性的注意力分布，并得到
$Z_i^{\mathrm{txt}}=[z_{i1}^{\mathrm{txt}},\ldots,z_{iL}^{\mathrm{txt}}]^{\top}
\in\mathbb{R}^{L\times d}$。

为控制文本证据的注入强度，对每个检查—标签对计算一个标量门控：
\[
g_{i\ell}=a_i\,\sigma\!\left(\rho_g([z_{i\ell}^{\mathrm{img}};z_{i\ell}^{\mathrm{txt}}])\right).
\]
随后通过残差连接进行融合：
\[
z_{i\ell}^{\mathrm{fuse}}
=z_{i\ell}^{\mathrm{img}}+g_{i\ell}z_{i\ell}^{\mathrm{txt}}.
\]
当没有有效报告时 $a_i=0$，门控自适应调节文本贡献，残差路径保留标签特异性的
视觉证据，最终得到
$Z_i^{\mathrm{fuse}}=[z_{i1}^{\mathrm{fuse}},\ldots,z_{iL}^{\mathrm{fuse}}]^{\top}
\in\mathbb{R}^{L\times d}$。
}


\subsection{Learning Objectives and Inference}
\label{sec:objectives}

A label-wise linear classifier is applied to each row of
$Z_i^{\mathrm{fuse}}$:
\begin{equation}
s_{i\ell}
=
w_\ell^{\top}z_{i\ell}^{\mathrm{fuse}}+b_\ell,
\qquad
p_{i\ell}=\sigma(s_{i\ell}).
\label{eq:lccf_classifier_new}
\end{equation}

\cntranslation{%
对最终融合矩阵 $Z_i^{\mathrm{fuse}}$ 的每一行使用一个标签级线性分类器，得到 logits 和预测概率：
\[
s_{i\ell}
=
w_\ell^{\top}z_{i\ell}^{\mathrm{fuse}}+b_\ell,
\qquad
p_{i\ell}=\sigma(s_{i\ell}).
\]
}

To account for the imbalance between positive and negative labels, we use
the asymmetric multi-label loss (ASL)~\cite{ridnik2021asymmetric}:
\begin{equation}
\begin{aligned}
\mathcal{L}_{\mathrm{ASL}}
&=-\frac{1}{|\mathcal{B}|L}
\sum_{i\in\mathcal{B}}\sum_{\ell=1}^{L}
\Bigl[
y_{i\ell}(1-p_{i\ell})^{\gamma_+}\log p_{i\ell}\\[-1mm]
&\qquad +(1-y_{i\ell})(1-\bar p_{i\ell})^{\gamma_-}
\log \bar p_{i\ell}\Bigr],\\
\bar p_{i\ell}&=\min(1,1-p_{i\ell}+m),
\end{aligned}
\label{eq:asl_new}
\end{equation}
where $\mathcal{B}$ denotes a training batch.

\cntranslation{%
为处理正负标签之间的不平衡，训练采用非对称多标签损失（ASL）
\cite{ridnik2021asymmetric}：
\[
\begin{aligned}
\mathcal{L}_{\mathrm{ASL}}
&=-\frac{1}{|\mathcal{B}|L}
\sum_{i\in\mathcal{B}}\sum_{\ell=1}^{L}
\Bigl[
y_{i\ell}(1-p_{i\ell})^{\gamma_+}\log p_{i\ell}\\[-1mm]
&\qquad +(1-y_{i\ell})(1-\bar p_{i\ell})^{\gamma_-}
\log \bar p_{i\ell}\Bigr],\\
\bar p_{i\ell}&=\min(1,1-p_{i\ell}+m).
\end{aligned}
\]
其中，$\mathcal{B}$ 表示训练批次。
}

For a valid report, we select a positive label $\ell$ and an absent label $r$,
replace the text retrieved for $\ell$ with that retrieved for $r$, recompute
the fused logit, and exclude co-positive label pairs.  Let
\begin{equation}
\mathcal{P}_i
=
\{(\ell,r):a_i=1,\ y_{i\ell}=1,\ y_{ir}=0\},
\qquad
Q=\sum_{i\in\mathcal{B}}|\mathcal{P}_i|.
\label{eq:lqd_pairs_new}
\end{equation}

\cntranslation{%
对于有效报告，选择一个正标签 $\ell$ 和一个缺失标签 $r$，用 $r$ 检索到的文本替换 $\ell$ 的文本并重新计算融合 logit，同时排除共为正的标签对。定义
\[
\mathcal{P}_i
=
\{(\ell,r):a_i=1,\ y_{i\ell}=1,\ y_{ir}=0\},
\qquad
Q=\sum_{i\in\mathcal{B}}|\mathcal{P}_i|.
\]
}

The LQD loss is defined as
\begin{equation}
\mathcal{L}_{\mathrm{LQD}}
=
\frac{1}{Q}
\sum_{i\in\mathcal{B}}
\sum_{(\ell,r)\in\mathcal{P}_i}
\frac{
\operatorname{softplus}(-s_{i\ell})
+
\operatorname{softplus}(\widetilde{s}_{i\ell\leftarrow r})
}{2},
\label{eq:lqd_new}
\end{equation}
with $\mathcal{L}_{\mathrm{LQD}}=0$ when $Q=0$.  This objective discourages
interchangeable textual evidence while avoiding the incorrect treatment of
coexisting positive labels as negative pairs.  The total training objective is
\begin{equation}
\mathcal{L}
=
\mathcal{L}_{\mathrm{ASL}}
+
\lambda_q\mathcal{L}_{\mathrm{LQD}}.
\label{eq:total_loss_new}
\end{equation}

\cntranslation{%
LQD 损失定义为
\[
\mathcal{L}_{\mathrm{LQD}}
=
\frac{1}{Q}
\sum_{i\in\mathcal{B}}
\sum_{(\ell,r)\in\mathcal{P}_i}
\frac{
\operatorname{softplus}(-s_{i\ell})
+
\operatorname{softplus}(\widetilde{s}_{i\ell\leftarrow r})
}{2}.
\]
当 $Q=0$ 时，令 $\mathcal{L}_{\mathrm{LQD}}=0$。该目标用于惩罚可相互替换的文本证据，同时避免将共存的正标签错误地作为负标签对待。总训练目标为
\[
\mathcal{L}
=
\mathcal{L}_{\mathrm{ASL}}
+
\lambda_q\mathcal{L}_{\mathrm{LQD}}.
\]
}

During inference, ALM-MIL takes one ordered image sequence and its paired
report with label-information masking as input, applies ACPE and LCCF, and
converts the $L$ logits with a sigmoid function.  A label is predicted when
its probability reaches the corresponding decision threshold of $0.5$.

\cntranslation{%
推理时，ALM-MIL 接收一组有序图像及其带标签信息掩码的配对报告，经过 ACPE 和 LCCF 后对 $L$ 个 logits 使用 sigmoid 函数。当标签概率不低于 $0.5$ 时输出该标签。
}
