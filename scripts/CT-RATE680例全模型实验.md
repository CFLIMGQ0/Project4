# CT-RATE680例三标签全模型实验

## 任务和范围

目标为肺气肿、肺不张、肺纤维化后遗改变的检查级多标签分类，使用固定680名患者的完整CT及官方英文报告。阳性数148/169/188；至少两项共阳性116例，其中三项阳性14例。包括全部单阳性和三项均阴性病例。

复用论文表2的实现：10种图像MIL基线、5种文本编码器、4种多模态融合基线、AMEF-MIL主要多模态路径，另外提供独立训练的AMEF纯图像路径。共21个模型、105个模型折次。四个多模态基线保持本项目的任务适配实现。

这是在胸部CT三标签任务上重新训练和评估的方法迁移实验；与直接使用胃镜权重的零样本外部测试区别记录在协议中。本轮沿用CQ500的冻结特征训练形式，并适配胸部CT输入，不修改论文或既有实验。

## 统一输入和划分

- 每名患者一例检查，每例64层：在完整轴位序列中均匀采样，少于64层时全部保留。固定RAS空间方向，统一切片显示方向。AMEF保留每张采样切片在原轴位序列中的索引及完整层数，实例丢弃后继续保留该对应关系。
- 使用fixed版本NIfTI已有的校正强度，不重复施加原DICOM截距。三通道分别采用窗位/窗宽：-600/1500、40/400、-600/700。缩放至224×224后按ImageNet统计量归一化。
- 冻结ImageNet ConvNeXt-Tiny，提取每层768维特征，所有图像和多模态方法共用同一缓存。学习投影层、MIL及后续模块；本轮不微调视觉主干。
- 文本仅使用官方`Findings_EN`，不输入`Impressions_EN`、临床信息、检查技术和标签。固定类别词与直接词形变体的掩码规则，正负病例一视同仁，原始下载报告保持不变。形态、位置等影像描述保留。
- 英文报告统一512 token上限、8192词表/哈希桶。普通词表仅在对应训练集构建，哈希编码使用既有稳定哈希接口。
- 种子42，患者五折各136例；每轮408训练、136验证、136测试。每折阳性数约30/34/38，共阳性23或24例；所有方法使用同一划分，每名患者仅一次进入测试。

人工标签来源于报告标注。此处目标词掩码是直接类别词的输入控制，相关描述仍然提供语义证据；本次不声称已完成独立影像标注或全面的信息泄漏审计。

## 训练与评价

图像与多模态方法复用现有缓存实验训练函数：30轮，batch size 16，AdamW，学习率0.0002，权重衰减0.02，20%预热及余弦调度，25%实例丢弃。分类损失采用ASL，各方法保持原辅助损失。AMEF主要多模态路径增加权重0.01的标签查询判别损失。为保护APro-CoPE位置间隔归一化，两条AMEF路径前向使用FP32，其他图像和多模态方法使用AMP。

五种文本基线复用原文本训练代码：最多50轮、耐心8、batch size 64、AdamW学习率0.0002及权重衰减0.0001，BCE正类权重仅从训练集计算。保留该类别原训练协议，与图像/融合方法的损失及早停准则分别记录。

图像/多模态权重按最低验证分类损失选择；文本权重按验证F1和早停选择。阈值仅由对应验证集确定，同时保存固定0.5阈值结果。测试数据不参与训练、选权重或调阈值。

AMEF的主要评分来自图文融合`logits`；额外的纯图像路径独立使用图像监督训练，未加入面向辅助图像输出的多模态教师蒸馏。因此该额外结果明确标记为独立训练的图像路径。

主表为五折测试Macro-F1均值和样本标准差；另存每标签F1、汇总OOF、Micro-F1，以及116例共阳性子集的Macro-F1和全标签完全匹配率。只对完整五折生成模型汇总，所有模型结果均保留。

## 启动与产物

在`src`目录执行：

```bash
python -u scripts/run_ctrate_680_pipeline.py
```

流水线先并行提取680例特征和运行五个文本基线，随后在4张GPU上补齐图像基线、多模态基线及AMEF，跳过协议一致且已完成的文本折次。文件锁阻止重复任务，源码或输入协议变化时停止，避免混用结果。

- `outputs/ct_rate_680/pipeline_state.json`：总阶段及进程状态。
- `outputs/ct_rate_680/experiment/`：输入掩码审计、患者映射、固定五折、准备协议及逐例特征。
- `outputs/ct_rate_680/all_models_fivefold/protocol.json`：训练设置、源码与输入SHA256。
- `outputs/ct_rate_680/all_models_fivefold/fold_*/模型名/`：训练历史、最佳权重、阈值、划分、预测及测试指标。
- `outputs/ct_rate_680/all_models_fivefold/progress.json`：已完成折次数。
- `outputs/ct_rate_680/all_models_fivefold/summary.csv`、`results.md`：完整五折的模型对比。
- `outputs/ct_rate_680/all_models_fivefold/*_oof_predictions.csv`：680例逐患者OOF预测，含原患者编号映射。

汇总过程重新核对预测概率、标签、阈值、每折F1及680例完整覆盖。包含报告内容的实验数据和患者输出留在本地，不随源码自动发布。
