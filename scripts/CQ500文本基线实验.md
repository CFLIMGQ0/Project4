# CQ500 图像派生文本的表2基线实验

本次针对491例CQ500的AI所见试稿，运行论文表2的五种纯文本模型：Hashed mean、Vocabulary attention、TextCNN、BiGRU和Transformer。模型实现直接复用 `exp_10/models.py`，训练直接复用 `exp_10/train_text_classification.py`。没有修改论文、既有模型实现或所见原文。

## 数据与划分

- 文本：`outputs/cq500/image_descriptions/uniform64/descriptions_draft.csv`，491例、491段，490种不同原文；不按文本重复情况删除病例。
- 标签：CQ500三位阅片者的多数票，标签顺序为IPH、Mass Effect、Midline Shift，阳性例数分别为134、127、65。
- 复用 `outputs/cq500/table2_image_baselines/patient_folds.json`，测试折例数为98、98、99、98、98。
- 每轮以一个折为测试集、下一个折为验证集，其余三个折为训练集。每个模型的491例均恰好获得一次折外预测。
- 本次沿用生成的原文，不额外进行类别词掩码或改写；常规字符分词、大小写规范化、截断与填充沿用文本模型实现。编号和真实标签不作为文本输入。
- 这些文字是图像派生AI试稿，不是独立采集的临床报告。

## 训练与评分

继承表2文本实现实际使用的 `configs/task2/exp10_text_classification.yaml`：最多50轮、早停耐心8轮、batch size 64、AdamW学习率0.0002、权重衰减0.0001、dropout 0.2、最大128个token。词表仅用对应训练折构建，容量上限8192；词嵌入128维、编码器512维、共同分类头隐藏层256维。损失为使用训练集阴阳性比例加权的BCE，不额外过采样。每折种子为2026加折号。

运行层面将数据加载进程数设为0，避免小型内存文本数据每轮反复创建进程；四张GPU并行执行25个折次。没有加载或微调Qwen进行此次分类训练。

每个epoch仅用验证集确定标签阈值，网格为0.10至0.90、步长0.05，以验证集Macro-F1选择最佳模型；最终测试集只用于评分。主结果为五折测试Macro-F1的均值与样本标准差。另外保存固定0.5阈值的结果，两种阈值口径分别标注。

## 输出与复现

```bash
python src/scripts/run_cq500_table2_text_baselines.py --devices 0 1 2 3
```

输出目录：`outputs/cq500/table2_text_baselines_uniform64/`。

- `results.md`、`summary.csv`、`summary.json`：五种模型的完整五折成绩及汇总折外指标。
- `*_oof_predictions.csv`：每模型491例的预测概率、阈值化预测、真实标签与测试折号。
- `fold_*/模型名称/`：词表、配置、训练/验证/测试编号、最佳模型、训练历史及逐折成绩。
- `protocol.json`、`data_audit.json`、`verification.json`：来源摘要值、标签与划分核对、2455行折外预测的独立F1复算记录。

全部25个折次已完成，训练任务无失败；从TP、FP、FN独立复算的F1与输出一致。运行支持按相同协议跳过已完成折次；改变输入、配置或实现时，需要使用新的输出目录。
