# CQ500 AMEF-MIL主要多模态路径

本实验补充此前四个多模态基线之外的AMEF-MIL结果。使用同一491例的图像缓存、uniform64生成文本及患者五折划分，保存于`outputs/cq500/amef_multimodal_uniform64/`。不改写论文、报告文本和原实验结果。

模型直接使用`Exp12AProCoPEWatchCrossAttentionTextCNNModel`：完整APro-CoPE、标签注意力MIL、标签超图、TextCNN、标签查询交叉注意力及门控残差融合。分类目标为论文主要多模态路径的ASL＋0.01标签查询判别损失。最终评分使用图文融合`logits`，而非`image_only_logits`。面向纯图像输出的教师蒸馏属于另一实验，本次不混入。

与四个多模态基线复用同一个训练函数、划分、实例选择、30轮、batch size 16、学习率0.0002、权重衰减0.02、20%预热和余弦衰减、25%实例丢弃。视觉使用冻结ConvNeXt-Tiny缓存，每例最多28层；文本为最多64张图像生成的一段AI试稿，编码上限128个token。它不是独立采集临床报告。

AMEF的位置适配以完整缓存轴位序列为参考，向APro-CoPE传入实例丢弃前的序列索引与长度，而非增强后的槽位编号；这些索引不代表全部原始DICOM文件的绝对索引。为保护APro-CoPE间隔归一化，前向计算使用FP32，与先前CQ500纯图像AMEF路径一致；四个多模态基线采用AMP。

权重仅按最低验证集分类损失选择，阈值仅根据选定权重的验证集预测确定；主结果为五折测试Macro-F1的均值和样本标准差，同时保留固定0.5阈值结果。

在`src`目录运行：

```bash
python scripts/run_cq500_amef_multimodal.py
```

输出包括五折最佳权重、训练历史、验证/测试预测、阈值、病例划分、输入和源码哈希，以及`summary.csv`、`results.md`。后者同时列出已完成的四个多模态基线，使用各自实际输出，不修改或重跑原基线。

可在训练结束后复核全部五折的权重、阈值、划分和F1：

```bash
python scripts/verify_cq500_amef_results.py
```

该命令还会重放491例的多模态预测，并将核对结果写入`verification.json`。
