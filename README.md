# EUS 检查数据集项目说明

## 项目定位

本仓库用于管理和检查 **EUS/GIST/Leiomyoma 相关患者检查数据集** 的目录结构与基础统计信息，重点关注：

- 患者级目录组织是否规范；
- 患者检查次数分布；
- 单次检查目录下 `img` / `pdf` 子目录是否完整；
- 为后续数据清洗、标注整理与建模提供基础统计依据。

## 当前数据目录约定

默认数据集根目录为：

```text
/home/Lim/datasets/eus-gist-leiomyoma/eus
```

目录组织约定如下：

```text
eus/
└── ZSxxxxxxxx/                   # 单个患者目录
    ├── ZSxxxxxxxx/               # 第 1 次检查目录
    │   ├── img/                  # 该次检查图片
    │   └── pdf/                  # 该次检查报告
    ├── ZSxxxxxxxx/               # 第 2 次检查目录
    │   ├── img/
    │   └── pdf/
    └── ...
```

说明：

- 数据集根目录下每个一级目录代表一名患者；
- 每名患者下可有 `1~n` 个检查目录；
- 每个检查目录下应包含 `img` 与 `pdf` 两类子目录；
- 实际检查目录名可能重复使用患者编号，也可能在患者编号基础上附加检查信息，项目统计脚本按“患者目录下的直接子目录”进行识别。

## 当前仓库内容

- `temp.py`：数据集结构检查与患者检查次数统计脚本；
- `requirements.txt`：Python 依赖声明；
- 文档文件：说明当前项目目标、目录约定与统计方式。

## 快速使用

在项目根目录运行：

```bash
python temp.py
```

如需显式指定数据根目录：

```bash
python temp.py --dataset-root /home/Lim/datasets/eus-gist-leiomyoma/eus
```

如需输出 JSON 结果：

```bash
python temp.py --save-json outputs/dataset_summary.json
```

## 脚本输出内容

`temp.py` 会输出以下信息：

1. 患者总数；
2. 检查总次数；
3. 每位患者检查次数分布，例如：
   - 1 次检查：100 个患者
   - 2 次检查：50 个患者
4. 缺少 `img` 或 `pdf` 子目录的检查目录数量；
5. 不符合预期命名的患者目录样例（如有）。
