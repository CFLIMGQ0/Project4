# CQ500四个多模态基线实验

本次对应论文表2的MMFNet、RadFuse、SAIF、MMTF，使用491例CQ500患者的图像缓存和已完成的AI影像描述。论文、原始标签、患者划分和生成文本均保持原样。

## 输入与划分

- 图像：`outputs/cq500/convnext_tiny_scan_features.npz`，复用先前图像基线的冻结ImageNet ConvNeXt-Tiny特征，每例一个所选轴位序列，最多28层。
- 文本：`outputs/cq500/image_descriptions/uniform64/descriptions_draft.csv`，每例一段。文本由该例均匀采样最多64张图像生成，属于图像派生AI试稿，而非独立采集的临床报告。
- 标签：`datasets/cq500/raw/reads.csv`，IPH、Mass Effect、Midline Shift；三位阅片者中至少两位标阳性为阳性。
- 划分：复用`outputs/cq500/table2_image_baselines/patient_folds.json`。第k折测试、下一折验证、其余三折训练；每例恰好产生一次测试预测。
- 分类训练允许以真实标签监督损失；推理接口仅接收图像和文本，不传入真实标签。文本原文不额外遮蔽或改写。

## 模型与训练

直接复用`sotas/task2/multimodal_sotas.py`的表2任务适配实现及`exp_8.models.TextCNNSequenceEncoder`，保持融合层不变。视觉backbone替换为此前CQ500图像实验同款缓存特征投影，后续实例投影仍参与训练。这里不是重新端到端训练ConvNeXt。

文本沿用多模态代码的`watch`字段哈希分词接口，8192个哈希槽、128个token上限、128维词嵌入、卷积核2/3/4、512维文本特征。字段名只是原实现接口，不引入CQ500之外的报告字段或真实标签。

训练配置沿用CQ500图像基线：30轮、batch size 16、AdamW学习率0.0002、权重衰减0.02、20%预热后余弦衰减、实例丢弃率0.25、折种子42+100×折号。使用ASL分类损失，同时保留各模型配置中的辅助损失：

| 模型 | 辅助损失及权重 |
|---|---|
| MMFNet | 图像分类0.1、文本分类0.1 |
| RadFuse | 对比损失0.1 |
| SAIF | 对齐损失0.1 |
| MMTF | 对齐损失0.1 |

所有模型以最低验证集分类损失选择权重，再在该权重的验证集预测上逐标签搜索阈值（0.10–0.90，间隔0.05）。测试集不参与权重或阈值选择。另保存同一权重下固定0.5阈值的结果。

## 运行与产物

在`src`目录运行：

```bash
python scripts/run_cq500_table2_multimodal_baselines.py
```

默认四个独立GPU工作进程，共20个模型折次。已完成折次可按协议摘要校验后续跑。输出位于`outputs/cq500/table2_multimodal_baselines_uniform64/`：

- `protocol.json`：配置、输入及关键源码SHA256。
- `run_state.json`、`progress.json`、`worker_*.log`：运行状态与进度。
- `fold_*/模型名/`：权重、轮次损失、划分ID、验证/测试逐例预测、阈值及指标。
- `summary.csv`、`summary.json`、`results.md`：五折汇总，标准差使用样本标准差。
- `*_oof_predictions.csv`：各模型完整491例折外预测。
- `verification.json`：独立重算阈值及F1、核对输入哈希和病例划分、重放保存权重的检查结果。

全部训练结束后，可独立复核并逐折重放保存权重：

```bash
python scripts/verify_cq500_multimodal_results.py --replay-checkpoints
```

主结果与刚完成的文本实验一致，报告验证集调阈值的Macro-F1；与此前固定阈值的图像结果对应时使用固定0.5列。不同实验的训练配置另有差别，不能仅凭相同折划分将其称作完全相同的训练协议。
