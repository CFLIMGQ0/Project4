# CQ500 图像派生描述

此流程为每例检查生成一段约 200 字的中文“影像所见”。输入来自本地 CQ500 的 DICOM 像素，输出属于 **AI 生成、尚待阅片复核的研究用描述**，不是数据集原始临床报告或医生签署的诊断报告。

此前全切片方案：Qwen3-VL-8B-Instruct 在视频、静态拼图及独立高分辨率图像的核对中出现主要密度描述不一致，尚未通过质量检查。旧试稿已标记否决，`pilot*` 和 `grounding_check*` 保留为排查记录。详见 `outputs/cq500/image_descriptions/quality_gate.json`。

输入整理已完成并核对 491 例：本地共 171,390 个 DICOM 文件，成功转换 171,389 帧，未抽样。病例 120 有 1 个源文件无法解码；病例 163 本地仅有 4 张图像。上述限制已保存在清单中。输入准备完成不代表影像描述已生成或通过质量审核。

## 当前方案：每例均匀采样64张

用户要求沿用本地模型，并将输入改为每例均匀采样最多64张；不足64张的全部保留。采样在每例完整缓存索引上等间距进行，覆盖首尾，不读取标签或预测来挑选图像。491例共选取30,270张，其中63例不足64张。原始图像和全量缓存保持不变。

新脚本 `run_cq500_uniform64_descriptions.py` 将所选三窗图像一次输入模型，直接输出每例一段约200字的所见，不进行自动重复改写。用户原始提示词和模型权重保持不变；补充输入说明如实交代均匀采样、序列边界及观察限制。输出同时保留模型原始文字、规范空白后的单段文字、实际采样索引和格式标记。

这次输出仍属于具有已知质量限制的研究用AI试稿，状态为 `not_reviewed`，不会把既有质量检查改成通过。新旧试稿分目录保存，已生成病例按相同协议断点续跑，禁止跨协议覆盖。

```bash
python src/scripts/run_cq500_uniform64_descriptions.py --sample-frames 64 --devices 0 1 3 --allow-unreviewed-drafts
```

输出目录为 `outputs/cq500/image_descriptions/uniform64/`：

- `descriptions_draft.csv`：实时汇总的“病例编号＋影像所见”，不是已审核临床报告。
- `cases/case_XXX.json`：逐例原始文字、采样与推理溯源。
- `progress.json`、`run_state.json`：已生成例数、缺失病例与运行状态。
- `generation_protocol.json`：原始提示词、模型、采样及生成设置。
- `worker_*.log`、`errors/`：工作进程日志和失败记录。

## 输入与覆盖

1. 扫描每例检查的全部本地 DICOM 序列。
2. 相同 SOPInstanceUID 的重复下载副本只处理一次，并记录重复文件路径。
3. 将每张可解码切片转换为三个独立灰度窗：脑窗（窗位 40、窗宽 80）、硬膜下窗（80、200）、骨窗（500、3000）。保留像素间距决定的纵横比例。
4. 在同一方向、同一序列内按空间位置排序。每窗缩放到 224×224 像素，三个窗水平并排。
5. 连续切片以视频张量形式输入视觉语言模型。关闭自动抽帧和再次缩放；逐段确认模型接收的帧数与输入帧数一致。
6. 综合各段图像观察，生成每例唯一一段检查级描述。解码失败、输入范围很少等情况记录在审计信息中，并在所见中保留必要的观察限制。

视图缩放和自动模型理解仍可能遗漏细微表现。覆盖全部可解码帧并不意味着达到医生完整阅片的准确性。

## 标签隔离

- 生成脚本不读取 `reads.csv`、既有分类预测或患者划分；运行时审计钩子会阻止这些文件被打开。
- 模型仅接收匿名像素张量、三窗顺序、几何方向和切片顺序说明。
- 患者编号、原始目录名、DICOM 自由文本以及疾病标签不写入模型提示。
- 对输出进行格式检查：病名、分类结论、阳性/阴性用语及无依据的数值需要改写或标记。
- 保留图像本身可见、可能与分类有关的证据。图像证据与标签相关不等于使用真实标签生成文本。
- 未根据分类性能挑选或改写描述；后续实验应把该文本明确标记为图像派生的合成文本，而非独立采集的临床文本模态。

## 文件

- `outputs/cq500/image_descriptions/views/case_XXX/manifest.json`：病例全部序列与切片覆盖清单、重复和失败记录。
- `outputs/cq500/image_descriptions/views/case_XXX/series_XXX.npz`：连续三窗图像。
- `outputs/cq500/image_descriptions/generated/chunk_notes/`：图像分段观察和推理信息。
- `outputs/cq500/image_descriptions/generated/case_XXX.json`：每例描述及溯源信息。
- `outputs/cq500/image_descriptions/generated/descriptions.csv`：逐例汇总。
- `outputs/cq500/image_descriptions/generated/generation_protocol.json`：原始提示词、提示词摘要值及生成设置。

生成模型：[Qwen3-VL-8B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct)。模型本身不是经本任务临床验证的自动阅片系统。`review_status` 默认保留 `not_reviewed`，格式检查通过不会改为医生审核通过。

## 运行

```bash
python src/scripts/prepare_cq500_report_views.py --workers 12
CUDA_VISIBLE_DEVICES=3 python -u src/scripts/generate_cq500_image_descriptions.py --device cuda:0
```

首次先使用 `--case-ids` 运行少量病例，结合图像检查输出，再进行批量生成。中途可从已有病例与片段记录恢复；若改动提示词或模型，应使用新的输出目录，避免混用生成协议。
