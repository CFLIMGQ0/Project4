# EUS 检查数据集项目说明

## 项目定位

本仓库用于管理和检查 **EUS/GIST/Leiomyoma 相关患者检查数据集** 的目录结构与基础统计信息，重点关注：

- 患者级目录组织是否规范；
- 患者检查次数分布；
- 单次检查目录下 `img` / `pdf` 子目录是否完整；
- 为后续数据清洗、标注整理与建模提供基础统计依据。

## 当前数据目录约定

项目的路径参数统一记录在 `configs/path.yaml` 中，包含数据根目录、输出目录、统计 JSON 路径和患者有效性表格路径。

如需查看路径字段含义或修改项目默认路径，请直接参考并维护 `configs/path.yaml`。

目录组织约定如下：

```text
eus-gist-leiomyoma/
└── ZSxxxxxxxx/                   # 单个患者目录
    ├── ZSxxxxxxxx/               # 第 1 次检查目录
    │   ├── img/                  # 该次检查图片
    │   └── pdf/                  # 该次检查报告
    ├── ZSxxxxxxxx/               # 第 2 次检查目录
    │   ├── img/
    │   └── pdf/
    └── ...
```

说明：

- 数据集根目录下每个一级目录代表一名患者；
- 每名患者下可有 `1~n` 个检查目录；
- 每个检查目录下应包含 `img` 与 `pdf` 两类子目录；
- 实际检查目录名可能重复使用患者编号，也可能在患者编号基础上附加检查信息，项目统计脚本按“患者目录下的直接子目录”进行识别。

## 当前仓库内容

- `temp.py`：数据集结构检查与统计入口脚本；
- `temp.md`：`temp.py` 的详细逻辑、路径配置与输出说明；
- `configs/path.yaml`：项目路径参数配置文件；
- 文档文件：说明当前项目目标、目录约定与数据情况。

## 快速使用

在项目根目录运行：

```bash
python temp.py
```

如需了解 `temp.py` 的参数、输出文件和患者有效性表格规则，请查看 `temp.md`。
